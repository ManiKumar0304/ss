BHAVANA & SURYA NITHISH - WEDDING INVITATION

All files are in the same folder:
- index.html
- style.css
- script.js
- README.txt

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a browser. For best results use VS Code + Live Server.
3. Internet is required for Bootstrap, Google Fonts and online Unsplash placeholder images.

WHAT TO EDIT
- Names, invitation wording, event details, venue and image URLs: index.html
- Colours, typography, layout and responsive styling: style.css
- Wedding countdown date/time and WhatsApp RSVP number: script.js
- Replace 91XXXXXXXXXX in script.js with the full WhatsApp number (country code + number, digits only).

All photos are online Unsplash placeholders. Replace their URLs with your own photos.

The reference URL could not be inspected pixel-by-pixel, so this is a complete elegant wedding invitation starter rather than a verified exact visual clone.
